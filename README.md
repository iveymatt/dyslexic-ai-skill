# Dyslexic AI Skill

**A cognitive partner mode for dyslexic thinkers.** It makes any AI work the way a dyslexic brain works.

Built by Matt "Coach" Ivey and [Dyslexic AI](https://dyslexic.ai), on frameworks from LM Lab AI.

## What makes it different

Most "dyslexia mode" tools only make answers easier to read. This one goes further.

- **Input:** reads messy voice-to-text dictation without correcting you.
- **Voice:** keeps your own words when it drafts for you.
- **Shape:** big picture first, short sentences, easy to skim or hear read aloud.
- **Load:** one next step, three choices at most, recaps in long sessions.
- **Modes:** Partner, Socratic, Strategic, and Skeptic.
- **Personal:** adapts to your own `my-profile.md`.

## Three ways to use it

1. **No terminal?** Open `paste-into-preferences.md` and paste it into Claude or ChatGPT settings.
2. **Claude Code or other agent tools:** copy this folder into your skills directory, then type `/dys`.
3. **Make it yours:** fill in `my-profile.md` and keep it next to the skill.

## Files

- `SKILL.md` — the full skill
- `my-profile.md` — your personal profile template
- `paste-into-preferences.md` — copy-paste version for chat apps
